# Workflow Create 功能使用指南

MatrixCode 现已支持创建 workflow 的工具和技能，让用户可以轻松制作自动化流程。

## 功能概览

### 1. workflow_create tool

**核心工具**，提供三种模式：

- **create**: 根据 JSON/YAML 定义创建并保存 workflow 文件
- **template**: 提供预定义的 workflow 模板
- **validate**: 验证 workflow 结构合法性

### 2. workflow-create skill

**交互式指导**，帮助 AI 理解如何与用户交互并设计 workflow。

## 使用方式

### 方式一：直接请求

用户说："创建一个研究 workflow"

AI 会：
1. 加载 workflow-create skill
2. 交互式收集需求（主题、深度、输出格式）
3. 调用 workflow_create tool 生成 YAML
4. 保存到 `.matrix/workflows/` 或 `~/.matrix/workflows/`

### 方式二：获取模板

用户说："给我一个批量处理的 workflow 模板"

AI 会：
```json
{
  "mode": "template",
  "template_type": "batch"
}
```

返回可用的模板，用户可修改后保存。

### 方式三：验证现有 workflow

用户说："验证这个 workflow 是否正确"

AI 会：
```json
{
  "mode": "validate",
  "yaml_content": "用户提供的 YAML"
}
```

返回验证结果和错误提示。

## 模板类型

工具提供 5 种内置模板：

1. **simple**: 简单线性流程
2. **parallel**: 并行执行流程
3. **condition**: 条件分支流程
4. **research**: 研究自动化流程（搜索 → 分析 → 报告）
5. **batch**: 批量处理流程

## 保存位置

- **project**: `.matrix/workflows/` - 项目级，团队共享
- **user**: `~/.matrix/workflows/` - 用户级，个人使用

## 示例：创建研究 workflow

**用户请求**：
> "创建一个研究 workflow，搜索关于 Rust 性能优化的内容，生成专业报告"

**AI 响应**：

1. 加载 skill
2. 收集需求：
   - 主题：Rust 性能优化
   - 深度：medium
   - 输出格式：Markdown
3. 调用 tool：
```json
{
  "mode": "create",
  "workflow": {
    "id": "rust-performance-research",
    "name": "Rust Performance Research",
    "inputs": [
      {"name": "topic", "type": "string", "required": true}
    ],
    "nodes": [
      {"id": "start", "type": "start", "name": "Start"},
      {"id": "search", "type": "task", "name": "Search", "task": "websearch"},
      {"id": "analyze", "type": "task", "name": "Analyze", "task": "analyze"},
      {"id": "report", "type": "task", "name": "Generate Report", "task": "content_generation"},
      {"id": "end", "type": "end", "name": "End"}
    ],
    "edges": [
      {"from": "start", "to": "search"},
      {"from": "search", "to": "analyze"},
      {"from": "analyze", "to": "report"},
      {"from": "report", "to": "end"}
    ]
  },
  "location": "project"
}
```

4. 返回结果：
```
✓ Workflow created successfully!

📄 File: .matrix/workflows/rust-performance-research.yaml
📁 ID: rust-performance-research
📝 Name: Rust Performance Research

[生成的 YAML 内容]

Use 'workflow_run' to execute this workflow.
```
